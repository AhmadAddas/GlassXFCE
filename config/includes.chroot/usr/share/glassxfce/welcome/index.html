Welcome to GlassXFCE

A lightweight Debian + XFCE desktop with a modern glass-inspired interface.

Fast launcher

Press Super + Space for the Spotlight-style application launcher.

Appearance

Press Super + Shift + A to toggle the bundled light and dark appearances.

Essentials

Super + Return opens Terminal. Super + E opens Files.

Live image

The Live session contains the complete GlassXFCE design. Use Install GlassXFCE when you are ready to copy it to disk.

Built on Debian

GlassXFCE keeps Debian 13 Trixie underneath and uses XFCE, Picom, Rofi and the WhiteSur visual themes.

Design goal

Modern rounded surfaces, blur and polished icons without replacing XFCE with a heavyweight desktop environment.

This page is stored locally and remains available without an internet connection.
